# 🦅 Flappy Bird 2:V

¡El clásico destruye-nervios ha vuelto, pero esta vez con gráficos optimizados, tienda de skins legendarias y una dificultad implacable! 

Diseñado para correr a los máximos fotogramas posibles usando aceleración por hardware y completamente adaptable para PC y Teléfonos Móviles.

## ✨ Características Principales

- 🚀 **Rendimiento Extremo:** Animaciones fluidas utilizando renderizado por hardware, sin tirones ni input lag.
- 📱 **Responsivo y Adaptable:** Escala perfecta en cualquier pantalla (Mobile First + PC) sin cortarse por las barras de navegación.
- 🛒 **SHOP (Armería Exótica):** Sistema de guardado local para tus puntos y monedas.
- 👹 **Skins Míticas Animadas:** Invierte tus monedas en diseños únicos con auras de CSS puro:
  - ⚡ *Dios Trueno*
  - 🛡️ *Colmillo de Acero*
  - 🪓 *Fantasma Espartano*
  - 👹 *Demonio Hanma*
  - 🐉 *Dragón del Vacío*
- 🎵 **Audio Integrado:** Banda sonora épica y efectos de sonido dinámicos generados por sintetizador web.

## 🕹️ Controles

* 💻 **En PC / Laptop:** Clic izquierdo del ratón o la tecla `Espacio`.
* 📱 **En Teléfono / Tablet:** Tocar cualquier parte de la pantalla.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura pura.
- **CSS3 Avanzado:** Flexbox, animaciones `@keyframes`, variables, sombras múltiples y filtros de alto rendimiento.
- **Vanilla JavaScript:** Motor de colisiones customizado, requestAnimationFrame, LocalStorage y AudioContext.
- **Cero Librerías:** 100% código nativo sin dependencias pesadas.
